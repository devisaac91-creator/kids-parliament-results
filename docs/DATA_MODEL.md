# Data Model

## Student Slip & Calculations
- **Subjects**: 4 Core (Maths, English, Science, Social) + 6 Electives.
- **Total Calculation**: 4 Core scores + Top 2 Elective scores (sum out of 600).
- **Pass Thresholds**: Subject pass is 50/100; total pass is 300/600.
- **Constraints**: No class positions or rankings are shown anywhere in the application.
